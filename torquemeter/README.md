### Installing

LabJack software must be installed in addition to python packages.

Get the download at [the official LabJack website][ref-ljm-sw] and follow the instructions.

Install python packages with
```
pip install -r requirements.txt
```

[ref-ljm-sw]: https://support.labjack.com/docs/ljm-software-installer-downloads-t4-t7-t8-digit
